2. ROOT CAUSES FOUND AND FIXED
------------------------------

2.1 Services page / STEP 6
    The Services DataGrid had a proportional first column with no minimum width.
    With the complete column set, the service-name cell collapsed and UIA could not
    discover the newly saved service. The service column now has a 230px minimum,
    ellipsis/tooltips, and an explicit automation name.

    The service editor also now awaits the catalog page reload before closing the
    dialog. This removes the race between the save result, debounced data notifier,
    and UI automation lookup.

2.2 Customer persistence assertion / STEP 15
    Search was correctly bound, but the seeded demo data makes the term "Example"
    match many generic @example.com email addresses. Alphabetical ordering could
    place the persisted "Jordan Example" outside the first page. Search results now
    prioritize a name match while retaining email and phone matches. A regression
    integration test covers this behavior.

    Customer search reload is also awaited through the page load gate, so a search
    typed while the initial page load is active is not lost.
